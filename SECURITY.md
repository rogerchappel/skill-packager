# Security

Please report security issues privately to the repository owner before opening a public issue.

## Scope

`skill-packager` is a local-first CLI. It reads local skill files and fixtures, then emits deterministic package artifacts and validation output. It should not receive secrets, tokens, proprietary prompts, private customer data, or unredacted logs as fixture input.

## Supported Versions

The current `0.1.x` line receives best-effort fixes while the API and package surface are still stabilizing.
